**1b. GRANTs — esto decide si el Plan 04 rompe el catalogo publico.**

```sql
SELECT p.oid::regprocedure AS firma, a.grantee, a.privilege_type
FROM pg_proc p
JOIN pg_namespace n ON n.oid = p.pronamespace
CROSS JOIN LATERAL aclexplode(COALESCE(p.proacl, acldefault('f', p.proowner))) AS a_raw
CROSS JOIN LATERAL (SELECT pg_get_userbyid(a_raw.grantee) AS grantee,
                           a_raw.privilege_type) AS a
WHERE n.nspname = 'public'
  AND p.proname IN ('get_my_linked_customers','get_products_public_sorted',
                    'get_all_sales_lines_admin','get_estadistica_clientes_agg',
                    'get_estadistica_madre_detail','get_customer_sales_history',
                    'get_my_assortment_18m','get_procesar_pedidos_recent',
                    'get_procesar_pedidos_stats')
ORDER BY 1, 2;
```

**2a. Firmas + huella de definicion.** El md5 de `pg_get_functiondef` es el detector: cambia
ante cualquier `CREATE OR REPLACE` accidental, aunque la firma quede igual.

```sql
SELECT p.oid::regprocedure AS firma,
       p.prosecdef AS secdef,
       md5(pg_get_functiondef(p.oid)) AS huella
FROM pg_proc p
JOIN pg_namespace n ON n.oid = p.pronamespace
WHERE n.nspname = 'public' AND p.proname LIKE 'fichaje%'
ORDER BY 1;
```
