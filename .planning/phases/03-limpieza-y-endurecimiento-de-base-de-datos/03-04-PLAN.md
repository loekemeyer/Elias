**2a. Conteo de overloads — la prueba de que el DROP hizo algo.**
```sql
SELECT p.proname, count(*) AS n_overloads,
       string_agg(p.oid::regprocedure::text, ' | ' ORDER BY p.oid::regprocedure::text) AS firmas
FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace
WHERE n.nspname='public'
  AND p.proname IN ('get_my_linked_customers','get_products_public_sorted')
GROUP BY p.proname ORDER BY 1;
```
Requerido: **2 filas, `n_overloads = 1` cada una**. Las firmas deben ser exactamente
`get_my_linked_customers()` y `get_products_public_sorted(text)`.

Si `get_my_linked_customers` quedo en `(uuid)` en vez de `()`, se dropeo la equivocada: **aplicar
`99-rollback.sql` seccion DATA-01 inmediatamente** y reportar.

**2b. Prueba de resolucion — que ya no diga "function is not unique".** Es el criterio literal de
la fase, y hay que probarlo llamando, no deduciendolo del conteo.
```sql
SELECT count(*) AS filas FROM public.get_products_public_sorted();
SELECT count(*) AS filas FROM public.get_products_public_sorted('catalogo');
SELECT count(*) AS filas FROM public.get_my_linked_customers();
```
Las 3 deben retornar sin error. La primera es la que antes fallaba con `function is not unique` y
ahora resuelve por el `DEFAULT 'ranking'`.

`get_products_public_sorted()` deberia devolver alrededor de **286 productos activos**
(`PROJECT.md`). Si devuelve 0, algo se rompio aunque no haya error — registrarlo y evaluar
rollback. `get_my_linked_customers()` puede devolver 0 legitimamente (depende de si el usuario de
la sesion tiene vinculos); 0 aca no es falla.

**2c. Verificar el ACL de `anon` — el punto de rotura del catalogo publico.**
```sql
SELECT p.oid::regprocedure AS firma, pg_get_userbyid(a.grantee) AS rol, a.privilege_type
FROM pg_proc p
JOIN pg_namespace n ON n.oid=p.pronamespace
CROSS JOIN LATERAL aclexplode(p.proacl) AS a
WHERE n.nspname='public' AND p.proname='get_products_public_sorted'
ORDER BY 2;
```
**Requerido: aparece `anon` con `EXECUTE`.** Si no aparece, todo visitante no logueado ve el
catalogo vacio — `script.js:772` corre en la rama `if (!logged)`. Corregir en el acto:
`GRANT EXECUTE ON FUNCTION public.get_products_public_sorted(text) TO anon;`
