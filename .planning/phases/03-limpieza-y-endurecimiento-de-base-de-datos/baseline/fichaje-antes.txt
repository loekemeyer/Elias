CORRECCION A LA LINEA BASE DECLARADA: el briefing de planificacion decia
37 RPCs. El conteo real es 34. Se usa 34 como linea base, tal como el
Plan 03-01 indica ("si no son 37, registrar el numero real y usar ESE").

La huella global es md5 del string_agg de los md5 de cada
pg_get_functiondef, ordenado por firma. Detecta:
  - una funcion agregada o eliminada
  - un CREATE OR REPLACE que cambie el cuerpo aunque conserve la firma
  - un cambio de search_path o de SECURITY DEFINER

Query para reproducir en el Plan 03-06 (debe dar identico):

  SELECT count(*) AS total_rpcs_fichaje,
         count(*) FILTER (WHERE prosecdef) AS security_definer,
         md5(string_agg(md5(pg_get_functiondef(p.oid)), '|'
             ORDER BY p.oid::regprocedure::text)) AS huella_global
  FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace
  WHERE n.nspname='public' AND p.proname LIKE 'fichaje%';
