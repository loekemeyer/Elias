---

### Camino A — Acceso al servidor IIS (el mas directo)

Si tenes acceso por RDP o consola al servidor que sirve el sitio:

1. Abrir **IIS Manager** (`inetmgr` desde Ejecutar).
2. En el panel izquierdo, expandir el servidor > **Sites**.
3. Buscar el sitio de `tierravintage.com.ar`. Click derecho > **Explore**.
   La ventana del explorador que se abre **es el webroot**. Copiar la ruta de la barra de direcciones.
4. Alternativa por linea de comandos, mas rapida y copiable:
   ```cmd
   %windir%\system32\inetsrv\appcmd.exe list site
   %windir%\system32\inetsrv\appcmd.exe list vdir
   ```
   El segundo comando imprime `physicalPath:` de cada sitio. Copiar la salida completa.
5. Estando en esa carpeta, listar que archivos sensibles llegaron:
   ```cmd
   dir storage-audit.js migration_tn.sql web.config .planning 2>nul
   ```

---

### Camino B — Panel de hosting de GoDaddy

Si el sitio esta en hosting administrado de GoDaddy (la IP 107.180.4.212 es de ellos):

1. Entrar a la cuenta de GoDaddy > **Mis productos** > el plan de hosting de `tierravintage.com.ar` > **Administrar**.
2. Buscar **Administrador de archivos** (File Manager) o los datos de **FTP**.
3. El directorio raiz que muestra el File Manager es el webroot. Suele ser `\httpdocs`, `\wwwroot` o `\public_html`. Anotar el nombre exacto.
4. Verificar dentro de esa carpeta si aparecen `storage-audit.js`, `migration_tn.sql`, `web.config` y la carpeta `.planning`.
5. En la seccion FTP, anotar el host FTP configurado — eso revela el mecanismo de deploy.

---

Esto no da la ruta fisica, pero SI responde lo que realmente importa para la fase:
